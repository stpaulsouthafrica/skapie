## How to run the session

1. Open the release build and make a blank board. Ask the participant to place **Text**, **LLM**, and **Conversation** by hand and make a Text → LLM Input cable. Start a timer when they open the palette. Record the first correct connection time; do not coach the first attempt.
2. Ask them to try one incompatible cable and describe the refusal in their own words. Record the exact attempted endpoints and any uncertainty.
3. On another blank board, add the coding workflow starter. Give them a disposable repository and a small patch task. Ask what they expect **Accept** to do before they click it. Check whether they can find the proposal diff, deliberately Apply, run the configured Check, and open the Result ledger.
4. Ask which animation showed an actual action and which was decoration. Record their own wording. Invite a clear **helps / neutral / distracts** judgment; do not infer this from a screenshot or successful build.
5. Record specific fixes or questions. Do not mark first-use acceptance complete until the record includes the participant's motion judgment from the running release app.
